# 오늘의 기록

날짜를 선택해 할 일과 하루 메모를 남기는 한국어 달력 앱입니다. HTML, CSS, JavaScript만 사용하며 빌드나 패키지 설치가 필요 없습니다.

## 기능

- 실시간 현재 날짜·시간 표시 (사용 중인 기기의 현지 시간)
- 월별 달력, 이전·다음 달 이동, 오늘로 돌아가기
- 날짜별 할 일 추가·완료·삭제와 진행률
- 날짜별 하루 메모 자동 저장 및 기록한 날짜 표시
- 월별 기록 일수·완료한 할 일 집계
- JSON 백업 내보내기·불러오기
- 모바일·태블릿·데스크톱 반응형 화면, 키보드 조작 지원

## 실행

`index.html`을 브라우저에서 열면 됩니다. 안정적인 저장과 실제 배포 환경 확인을 위해서는 정적 웹 서버 또는 Vercel 주소로 접속하는 것을 권장합니다.

## GitHub에 올리기

GitHub에서 빈 저장소를 만든 뒤 프로젝트 폴더에서 실행합니다. `<저장소 주소>`는 본인의 GitHub 저장소 주소로 바꾸세요.

```sh
git add .
git commit -m "Create daily journal calendar app"
git branch -M main
git remote add origin <저장소 주소>
git push -u origin main
```

이미 origin이 등록돼 있다면 `git remote add` 단계는 생략하세요.

## Vercel 배포

1. Vercel에서 **Add New → Project**를 선택합니다.
2. 위 GitHub 저장소를 Import합니다.
3. Framework Preset을 **Other**로 선택합니다.
4. Root Directory는 기본값인 저장소 루트를 사용합니다.
5. Build Command와 Output Directory는 별도로 지정하지 않고 기본값으로 둡니다. 이 프로젝트는 빌드 과정이 없습니다.
6. 환경 변수 없이 Deploy합니다.

공식 안내: https://vercel.com/docs/deployments

## 저장 방식

기록은 현재 브라우저의 `localStorage`에 저장됩니다. 로그인과 서버 저장은 아직 포함하지 않습니다. 브라우저·기기·도메인이 달라지면 기록이 공유되지 않습니다. 로컬에서 작성한 기록을 배포 주소로 옮기려면 백업 내보내기 후 새 주소에서 불러오세요. 브라우저 데이터 삭제 시 기록도 지워지므로 정기적으로 백업하세요.

백업을 불러오면 다른 날짜의 기록은 유지되며, 같은 날짜의 기록은 백업 내용으로 바뀝니다. 메모는 날짜당 50,000자, 할 일은 항목당 300자 및 날짜당 1,000개까지 지원합니다.

웹 폰트는 Google Fonts에서 불러오며, 연결되지 않으면 시스템 글꼴을 사용합니다. 나머지 앱 기능은 외부 라이브러리 없이 동작합니다.

## 파일 구성

- `index.html`: 화면 구조
- `styles.css`: 달력·반응형 디자인
- `app.js`: 날짜·기록·브라우저 저장·백업 처리
- `vercel.json`: Vercel 정적 배포 설정

Supabase 회원가입·로그인과 사용자별 서버 저장은 다음 단계에서 연결할 수 있습니다. 정적 HTML은 Vercel 환경 변수를 브라우저에서 직접 읽을 수 없으므로, 연결 시 공개 설정을 전달하는 서버 엔드포인트 또는 빌드 단계가 필요합니다.
